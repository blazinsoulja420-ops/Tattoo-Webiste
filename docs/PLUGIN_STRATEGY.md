# Plugin / Connector Strategy

Primary integrations:

- GitHub — source of truth and CI;
- Figma — UI/UX design;
- Prompt Perfect — prompt refinement;
- OpenAI developer tooling — AI integration guidance;
- Notion / Google Drive — supporting project documentation and assets;
- Canva — marketing creative;
- Vercel — deployment candidate;
- Supabase — backend candidate.

Connector availability never grants repository, deployment, payment, or production authority.
