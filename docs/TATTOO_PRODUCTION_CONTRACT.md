# Tattoo Production Contract

## FTA
Finished Tattoo Artwork: high-resolution intended finished appearance.

## ACR
Artist Construction Reference: detailed professional reference with a genuinely hand-drawn pencil, graphite, ink, or sketch presentation. A grayscale render is insufficient.

## TRS
Transfer-Ready Stencil: essential linework prepared for physical transfer workflows, including scale, optional mirroring, tiling, and line hierarchy.

All outputs must preserve canonical geometry. Material drift is a production failure. Passing this contract creates a production candidate only and does not independently authorize tattoo execution.
